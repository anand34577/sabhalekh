# Keyboard shortcuts

## Anywhere in Windows

| Shortcut | Action |
|---|---|
| **Ctrl+Shift+R** | Start or stop recording, even when Sabhalekh is minimised. You can change it in **Settings → Shortcuts & startup**. |

## In the Sabhalekh window

| Shortcut | Action |
|---|---|
| **Ctrl+O** | Upload media files |
| **Ctrl+Shift+E** | Export several meetings at once |
| **Ctrl+F** | Find in the open transcript |
| **Space** | Play / pause |
| **←** / **→** | Back / forward 10 seconds |

## While finding in a transcript

| Shortcut | Action |
|---|---|
| **Enter** | Next match |
| **Shift+Enter** | Previous match |
| **Esc** | Close the search |

## While editing a line

| Shortcut | Action |
|---|---|
| **Enter** | Save |
| **Shift+Enter** | New line inside the text |
| **Esc** | Cancel |

## Changing the recording hotkey

1. Open **Settings → Shortcuts & startup**.
2. Click the **Start / stop recording hotkey** box.
3. Press the new combination, for example **Ctrl+Alt+M**.

If the shortcut doesn't respond, another app is probably using the same keys. Pick a different combination.
